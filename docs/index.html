CyberToolkit

A command-line network security utility collection

GitHub Repository

Tools

Port Scanner

Scans TCP ports on a host to identify open connections.

When to use: Network reconnaissance, vulnerability assessment.

python cybertoolkit.py -s 192.168.1.1 80-100

Banner Grabber

Connects to a host and port to retrieve service banners.

When to use: Service identification, version detection.

python cybertoolkit.py -b google.com 80

SHA-256 File Hash

Computes SHA-256 digest of files for integrity verification.

When to use: File verification, malware analysis.

python cybertoolkit.py -f example.txt

DNS Lookup

Resolves domain names to IP addresses.

When to use: Domain investigation, network troubleshooting.

python cybertoolkit.py -d google.com

Password Generator

Generates cryptographically secure random passwords.

When to use: Secure credential generation, password management.

python cybertoolkit.py -p 16

Getting Started

Clone and run the project:

git clone https://github.com/kurt-sudo420/CyberToolkit.git
cd CyberToolkit
python cybertoolkit.py

Requirements: Python 3.6+
